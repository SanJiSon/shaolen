# История изменений

Формат: версия, дата, список изменений (markdown). В конце блока — краткий текст поста для канала [@shaolenai](https://t.me/shaolenai) в комментарии `<!-- TELEGRAM_POST ... -->`. **Версия хранится только в репозитории** (файл `VERSION` и блок здесь); из Telegram-канала версия не читается. Служба публикации читает версию из `VERSION`, находит текст поста в этом файле и при появлении новой версии отправляет пост в канал через MTProto.

## Как добавлять новые версии

1. **Запишите новую версию в файл `VERSION`** (одна строка, например `1.1.1`). Либо запустите `scripts/bump_version.py` (patch / minor / major).
2. В начале этого файла (после `---`) вставьте новый блок по образцу выше с той же версией (`v1.1.1` и т.д.).
3. Укажите дату в формате `YYYY-MM-DD`.
4. Опишите изменения в списке (markdown).
5. В конце блока добавьте комментарий:
   ```
   <!-- TELEGRAM_POST
   Краткий текст поста для канала (1–3 абзаца, эмодзи по желанию).
   -->
   ```
6. После деплоя скрипт публикации прочитает первую строку `VERSION`; если после версии **нет знака `+`**, отправит пост в канал и поставит `+`. Новая версия в `VERSION` добавляется следующей строкой (первой), предыдущая уходит ниже с `+` (удобно через `scripts/bump_version.py`).
