Воркер напоминаний работает по московскому времени. Установка: sudo cp systemd/goals-reminder.service /etc/systemd/system/ && sudo systemctl daemon-reload && sudo systemctl enable goals-reminder && sudo systemctl start goals-reminder

Если веб-приложение остановлено, кнопка «Запустить» для webapp может вернуть 502 — запрос идёт через него. Запустите на сервере: systemctl start goals-webapp
